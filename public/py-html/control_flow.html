# Logic & Loops • 20 Min Read • Core Decision Engine

Control Flow & Conditionals

Programs need to make decisions and repeat actions. In this lesson, discover how to direct code execution using if, elif, else, and loops (for / while).

1 Decision Making: if, elif, else

Python uses indentation (4 spaces) rather than curly braces to define code blocks. This enforces readable and clean code structure.

conditional_check.py 
score = 88

if score >= 90:
    grade = "A+ (Outstanding)"
elif score >= 80:
    grade = "A (Excellent)"
elif score >= 70:
    grade = "B (Good)"
else:
    grade = "Keep Practicing!"

print(f"Score: {score} => Evaluation: {grade}")
--- Terminal Output ---
Score: 88 => Evaluation: A (Excellent)

2 Loops: For Loops & While Loops

Loops allow you to iterate over sequences or repeat tasks until a condition is satisfied.

loops_demo.py 
# Iterating over range with enumerate
frameworks = ["React", "FastAPI", "Django", "Flask"]

for index, tech in enumerate(frameworks, start=1):
    print(f"[{index}] Exploring {tech} with Python")
--- Terminal Output ---
[1] Exploring React with Python
[2] Exploring FastAPI with Python
[3] Exploring Django with Python
[4] Exploring Flask with Python
