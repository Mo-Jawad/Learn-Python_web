# Collections • 25 Min Read • Essential Mastery

Python Data Structures

Discover Python's 4 core built-in data collections: Lists (ordered, mutable), Tuples (ordered, immutable), Dictionaries (key-value hash maps), and Sets (unique elements).

1 Lists & Dictionaries in Action

collections_demo.py 
# Dictionary representing a developer profile
developer = {
    "name": "Md Jaoyad SWE",
    "skills": ["Python", "React", "FastAPI", "Tailwind"],
    "experience_years": 3,
    "is_open_to_collaborate": True
}

# List Comprehension for filtering
modern_skills = [skill.upper() for skill in developer["skills"]]

print(f"Dev: {developer['name']}")
print(f"Uppercased Skills: {modern_skills}")
--- Terminal Output ---
Dev: Md Jaoyad SWE
Uppercased Skills: ['PYTHON', 'REACT', 'FASTAPI', 'TAILWIND']
