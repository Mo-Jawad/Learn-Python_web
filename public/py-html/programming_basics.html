1 Your First Python Program: "Hello, World!"

Python is famous for its clean, human-readable syntax. Unlike C++ or Java, Python does not require boilerplate classes or semicolon terminators to print text to the console.

hello_world.py 
# Welcome to Python!
print("Hello, World!")
print("Welcome to Py-Learn-HTML created by Md Jaoyad SWE 🚀")

Hello, World!
Welcome to Py-Learn-HTML created by Md Jaoyad SWE 🚀

2 Variables and Primitive Data Types

In Python, variables are dynamically typed containers. You don't need to specify int or String; Python detects the type automatically at runtime!

1. Integer (int) & Float (float)

age = 25
price = 99.95

2. String (str)

platform = "Py-Learn-HTML"
author = 'Md Jaoyad'

3. Boolean (bool)

is_active = True
is_completed = False

4. Type Checking (type())

print(type(age)) # <class 'int'>

variables_demo.py 
# Variable declarations
user_name = "Alex"
lessons_completed = 5
python_mastery_score = 92.5
is_certified = True

print(f"Learner: {user_name} | Progress: {lessons_completed} lessons | Score: {python_mastery_score}%")
print(f"Certified Status: {is_certified} (Type: {type(is_certified).__name__})")
--- Terminal Output ---
Learner: Alex | Progress: 5 lessons | Score: 92.5%
Certified Status: True (Type: bool)
